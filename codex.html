Le Codex des Failles

Ce codex rassemble les personnages, pouvoirs, lieux, objets, concepts et événements établis dans le Tome I de LES FAILLES. Le Tome I s’organise en deux ensembles distincts : l’Arc 1, à fonction encyclopédique, présente les protagonistes et les grandes forces cosmiques ; l’Arc 2 — L’Ère du Renouveau déplace le récit dans Neo‑Memoria, la réalité reconstruite après l’Apocalypse.

Avertissement de canon — ce document n’a pas vocation à remplacer le texte du Tome I : il l’organise. Lorsqu’un élément est mystérieux, incomplet ou présenté sous plusieurs états, il reste présenté comme tel plutôt que d’inventer une explication. Le Tome II — Les Fils Croisés — est volontairement exclu de ce codex.

Crédit d’idée originale · Nassim Delbos & Garrice Relaix
